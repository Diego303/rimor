# F0-7 · CORS de las APIs

- **Fecha:** 2026-10-18
- **Estado:** hecha. Comprobadas las cabeceras CORS reales de cada API con `curl`, enviando `Origin` de una página de GitHub Pages (`https://ejemplo.github.io`) y, donde hace falta, la petición previa `OPTIONS`. Es exactamente lo que el navegador evalúa; la prueba desde una página real queda como confirmación humana.
- **Decide:** alcance de IN-041.

## Resultados

| API | Petición | `Access-Control-Allow-Origin` | ¿Sirve desde el navegador? |
|---|---|---|---|
| GitHub | `GET api.github.com/repos/{o}/{r}` (y `/releases/latest`) | `*` | **Sí** |
| GitHub con token | `OPTIONS` con `Authorization` | `*`, admite `Authorization` | **Sí** (token opcional del usuario) |
| GitLab | `GET gitlab.com/api/v4/projects/{id}` | `*` | **Sí** |
| Crossref | `GET api.crossref.org/works/{doi}` | `*` | **Sí** |
| Crossref BibTeX | `GET …/works/{doi}/transform/application/x-bibtex` | `*` | **Sí** |
| doi.org con `Accept: application/x-bibtex` | redirección a Crossref | origen reflejado y `*` | **Sí** |
| DataCite | `GET api.datacite.org/dois/{doi}` | origen reflejado | **Sí** |
| OpenAlex | `GET api.openalex.org/works/doi:{doi}` | `*` | Sí, pero desde febrero de 2026 pide clave (plan §8.6): fuera de alcance |
| **arXiv** | `GET export.arxiv.org/api/query?id_list=…` | **ninguna** (respuestas 200, 429 y 503 sin la cabecera) | **No** |
| npm | `GET registry.npmjs.org/{paquete}` (también abreviado) | `*` | **Sí** |
| crates.io | `GET crates.io/api/v1/crates/{c}` | `*` (exige `User-Agent`, que el navegador siempre envía) | **Sí** |
| PyPI | `GET pypi.org/pypi/{p}/json` | `*` | **Sí** |
| deps.dev | `GET api.deps.dev/v3/systems/{s}/packages/{p}` | `*` | **Sí** |
| OSV | `POST api.osv.dev/v1/query` (con petición previa) | origen reflejado | **Sí** |
| Go (proxy.golang.org) | `GET …/@latest` | `*` | **Sí** |
| Maven Central | `GET search.maven.org/solrsearch/select` | **ninguna** | **No** |

## Decisión para IN-041

- **Repositorio:** GitHub (con token opcional, guardado en local) y GitLab.
- **Paquetes:** deps.dev como fuente principal (versiones, licencias, dependencias y avisos para npm, PyPI, Cargo, Go y Maven), más npm, crates.io y PyPI para la fecha de la última versión, y OSV para vulnerabilidades. Maven se cubre solo por deps.dev.
- **Papers:** Crossref para DOI (metadatos y BibTeX). **arXiv no admite CORS**: un enlace `arxiv.org/abs/XXXX` se enriquece por su DOI de DataCite `10.48550/arXiv.XXXX` (metadatos) y Crossref/doi.org con `Accept: application/x-bibtex` para el BibTeX. Si DataCite no responde, la ficha queda «sin enriquecer».
- La CSP (`connect-src`) se genera con exactamente estos dominios cuando el usuario los activa en Ajustes: `api.github.com`, `gitlab.com`, `api.deps.dev`, `registry.npmjs.org`, `crates.io`, `pypi.org`, `api.osv.dev`, `api.crossref.org`, `doi.org`, `api.datacite.org`.
