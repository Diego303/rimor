# F0-1 · OPFS a escala

- **Fecha:** 2026-10-18
- **Estado:** parcial. La medición en navegadores reales queda pendiente de validación humana.
- **Decide:** diseño del adaptador de IN-005 y textos de persistencia de IN-007.

## Qué se quería medir

Escribir y leer 5.000 archivos `.md` de 2 a 20 KB desde un Worker con `createSyncAccessHandle`, en Chrome, Firefox y Safari, y el resultado de `navigator.storage.persist()` con y sin la PWA instalada. Criterio: lectura completa en menos de 2 s y persistencia concedida al menos en Chrome con la PWA.

## Qué se ha podido hacer

Nada de la medición: OPFS solo existe en un navegador y, por instrucción del autor (2026-10-18), en esta etapa no se usa Playwright ni ningún navegador automatizado. No se inventan cifras.

Lo que sí queda hecho:

1. **El script de medición** (anexo), listo para pegarlo en la consola de cada navegador sobre la web publicada (OPFS exige contexto seguro: `https` o `localhost`).
2. **Una decisión de diseño** que no depende de las cifras exactas y que se puede ajustar sin tocar la interfaz `Almacen` cuando lleguen los datos.

## Lo que se sabe sin medir (documentación pública)

- `navigator.storage.getDirectory()` y `FileSystemSyncAccessHandle` (solo en Workers dedicados) están disponibles en las versiones actuales de Chrome/Edge, Firefox y Safari.
- `persist()`: Chromium la concede sin preguntar según el uso del sitio (instalar la PWA o marcarlo ayuda); Firefox pregunta al usuario; Safari decide por heurísticas propias (instalar en la pantalla de inicio es la vía más fiable). En una ventana privada el almacenamiento se borra al cerrarla.

## Decisión

1. **Adaptador OPFS en un Worker dedicado** (`almacen.worker.ts`) con `createSyncAccessHandle` y Comlink, como propone el plan. Si el navegador no tiene `createSyncAccessHandle`, el mismo Worker usa `createWritable()` (asíncrono). La interfaz `Almacen` no cambia.
2. **Lectura por lotes:** `listar` recorre carpetas por fecha (`elementos/AAAA/MM/`), así que ninguna carpeta crece sin límite; la apertura de un espacio no lee los 5.000 archivos sino la caché de IndexedDB (IN-006), y solo reconcilia diferencias.
3. **Persistencia (IN-007):** se pide al crear el primer espacio, tras una frase que explica por qué; se guarda el resultado y se muestra en «Datos y copias». Nunca bloquea. Si no se concede, el recordatorio de copia (IN-037) es la red de seguridad.

Si la medición real supera los 2 s de lectura completa, la respuesta prevista en el plan (§15, riesgo «OPFS lento») es mantener la caché en memoria y leer en lotes desde el Worker; ambas cosas ya están en el diseño.

## Pendiente de validación humana

Ejecutar el anexo en Chrome, Firefox y Safari (con y sin la PWA instalada, cuando exista en IN-050) y anotar aquí: tiempo de escritura, tiempo de lectura completa y resultado de `persist()`.

## Anexo: script de medición

```js
// Pegar en la consola de la web publicada. Crea /f0-1/ en OPFS y lo borra al final.
const codigo = `
self.onmessage = async () => {
  const raiz = await navigator.storage.getDirectory();
  const dir = await raiz.getDirectoryHandle('f0-1', { create: true });
  const enc = new TextEncoder();
  const t0 = performance.now();
  for (let i = 0; i < 5000; i++) {
    const tam = 2048 + Math.floor(Math.random() * 18432);
    const fh = await dir.getFileHandle('e' + i + '.md', { create: true });
    const h = await fh.createSyncAccessHandle();
    h.truncate(0); h.write(enc.encode('x'.repeat(tam)), { at: 0 }); h.flush(); h.close();
  }
  const t1 = performance.now();
  let bytes = 0;
  for await (const [, fh] of dir.entries()) {
    const h = await fh.createSyncAccessHandle();
    const buf = new Uint8Array(h.getSize()); h.read(buf, { at: 0 }); bytes += buf.length; h.close();
  }
  const t2 = performance.now();
  await raiz.removeEntry('f0-1', { recursive: true });
  postMessage({ escrituraMs: Math.round(t1 - t0), lecturaMs: Math.round(t2 - t1), bytes });
};`;
const w = new Worker(URL.createObjectURL(new Blob([codigo], { type: 'text/javascript' })));
w.onmessage = async (e) => console.log(e.data, 'persist:', await navigator.storage.persist());
w.postMessage(null);
```
